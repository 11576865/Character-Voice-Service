# 角色语音试听验收

本表只记录真实试听，不以 HTTP 200 或测试 WAV 代替主观质量判断。每次比较同一角色、同一文本、同一模型与速度，分别选默认参考、自动参考和人工参考。

| 日期 | 角色/模型 | 书籍与段落 | 模式及实际参考 ID | 音色一致性 1–5 | 情绪匹配 1–5 | 发音 1–5 | 段落衔接 1–5 | 等待秒数 | 失败或修正记录 |
|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |

建议固定样本至少包含平静叙述、快乐、悲伤、愤怒、惊讶、含人名的英文对话以及连续多段对话。每组先盲听，再看实际参考 ID。出现明显音色漂移、情绪不合或切换突兀时，保留手动参考；只有稳定胜过默认参考后才为该角色启用自动模式。

本仓库只有 `voices/example.json` 模板，不含真实模型与参考 WAV。实际验收需使用用户本机角色配置和人工挑选的 Reference Pack。自动情绪判断与跨角色建议均须经过此表记录后才能作为默认行为。
